# 公開のしくみと手順

## 公開URL

**https://98rcsk-creator.github.io/myhero/**

このURLを送れば、誰でもスマホやパソコンで遊べます。
アプリのインストールは不要です。

## しくみ（かんたんに）

```
index.html を main ブランチに入れる
        ↓
GitHub が自動でページを作り直す（1〜2分）
        ↓
公開URLが新しくなる
```

GitHub Pages という無料のしくみを使っています。

大事なポイントは3つです。

1. **公開されるのは `main` ブランチの `index.html` だけ**
   → 別の名前のファイルや、別のブランチに置いても公開されません
2. **`docs/` フォルダは公開ページに影響しない**
   → ドキュメントを増やしてもゲームは変わりません
3. **`index.html` は1ファイルで完結している**
   → 画像やJSの外部ファイルがないので、置くだけで動きます

## 更新の手順

AI（Claude Code）に作業を頼む場合、あなたがやることは最後の1ステップだけです。

| 手順 | 誰がやる |
|------|---------|
| 1. コードを変更する | AI |
| 2. コミットする | AI |
| 3. 作業ブランチにプッシュする | AI |
| 4. プルリクエスト（PR）を作る | AI |
| 5. **PRをマージする** | **あなた** |
| 6. 公開ページが自動更新される | GitHub（自動・1〜2分） |

### 5番の具体的なやり方

1. AI から送られた PR のリンクを開く（iPhone の Safari でOK）
2. 下にスクロールして、緑色の **「Merge pull request」** ボタンを押す
3. 確認で **「Confirm merge」** が出るので、それも押す
4. 紫色の「マージされました」という画面が出たら成功

> 「ブランチを削除」というボタンも出ますが、**押さなくて大丈夫**です。
> 押しても安全ですが、押す必要もありません。

### 更新できたかの確認

1〜2分待ってから **https://98rcsk-creator.github.io/myhero/** を開きます。

古いままに見えるときは、ブラウザが前の内容を覚えているだけなので、
**ページを再読み込み**してください（Safari なら画面を下に引っ張る）。

## 元に戻したいとき

公開後に問題が見つかっても、以前の版は Git の履歴にすべて残っています。
AI に「前の版に戻して」と伝えれば戻せます。ファイルが消えることはありません。

## 注意点

- **セーブデータは端末のブラウザに保存されます。**
  ゲームを更新してもデータは消えませんが、
  ブラウザの「履歴・サイトデータを消去」をするとゲームのデータも消えます。
- 別の端末・別のブラウザにはデータは引き継がれません。
