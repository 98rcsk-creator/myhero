### スプライトの実寸と、ゲーム内の表示サイズ

現行スプライトは 62〜100px 四方。表示サイズはワールドで大きく変わる（`baseW=16+sEff*2`）。

| ワールド | 通常敵の表示 | 巨体の表示 | 現行62pxの絵は |
|---|---|---|---|
| W1 | 22×26 | 37×44 | 過剰（2.8倍） |
| W4 | 52×56 | 88×95 | ほぼ適正 |
| W7 | 82×86 | 139×146 | 不足 |
| W10 | 112×116 | 190×197 | 大幅に不足 |

→ **一律縮小は不正解。序盤ワールド用は小さく、終盤用は大きく**が正しい。

### メモリの壁（SPEC §4-11）

> iOS Safariのメモリ制約：base64画像を同時に増やしすぎるとモバイルで読み込み失敗する

89体を現行と同じ密度で積むと **+約1MB**、ファイルは 2.1MB 級になる。
**素直に全部積むとiPhoneで開けなくなる危険がある。** 段階導入と解像度の最適化が必須。

## 4. 実装の段取り（提案）

### フェーズ1：見た目の差し替え基盤（**新しい動きゼロ**）
- `ENEMY_SPR[type]` を `ENEMY_SPR[world][type]` 相当の引き方に変更

- ここが通れば、あとは同じ手順の繰り返し

敵ごとの `sprS`（生成時に固定する乱数）で絵を選ぶ。W4の10体で **+65KB（HTML +8%）**。
ヘッドレス検証：W4は10枚すべてロードされ雪山の絵で描画、W1/W7は従来絵のまま（退行なし）、JSエラー0件。

## 7. 背景との同化対策（v240で確立・以後すべてのまものに適用）

ユーザー指摘「背景と同化してない？」を受けて実測したところ、**雪山10体のうち7体が基準割れ**していた。

### 測り方
不透明ピクセルの平均色と、そのワールドで敵が立つ帯の背景平均色から **WCAG コントラスト比**を出す。
基準は「今まで問題なく遊べてきた組合せ」＝既存まもの×草原の **1.65〜3.69（平均2.45）**。

### v240 実測（輪郭なし・雪山背景 RGB(187,205,214)）

| まもの | 比 | | まもの | 比 |
|---|---|---|---|---|
| ツラランリン | **1.02** 🔴 | | ユキダルン | 1.71 ✅ |
| ブリザード | 1.09 🔴 | | スコア外… | |
| フロストン | 1.21 🔴 | | ヒョウガ | 1.42 🔴 |
| シロクマ | 1.21 🔴 | | ペンペン | 2.59 ✅ |
| アイスン | 1.25 🔴 | | スノーウルフ | 2.12 ✅ |
| モコモコ | 1.33 🔴 | | | |

→ 平均1.50・最低1.02（ほぼ不可視）。**「雰囲気が合う」ことと「見える」ことは別問題**だった。

### 対策：輪郭線を絵に焼き込む

切り出し時にアルファを膨張させ、外周に濃い縁（`#262A3A` α235）を作ってから元絵を重ねる。
**実行時の処理は増えない**（描画コードは不変）。

| 太さ | 縁のコントラスト比（最低／平均） | 基準割れ |
|---|---|---|
| なし | 1.02 / 1.50 | 7/10体 |
| 1px | 2.61 / 3.21 | 0/10体 |
| **2px（採用）** | **8.69 / 8.69** | **0/10体** |

2pxを採用（低学年が遊ぶ前提のため見やすさ優先）。**サイズはむしろ11KB減った**（縁が均一色で圧縮が効くため）。

### v244で判明：輪郭の色は背景の明暗で変える（CLAUDE.md §1-11）

W2（夕暮れの森）の敵が立つ帯の背景は **RGB(135,66,18)・輝度0.09** と暗い。
ここに v240 の濃紺 `#262A3A` を当てると**足すほど悪化**した。

| 輪郭 | W2でのまもの平均比（最低〜最高） | 判定 |
|---|---|---|
| なし | 1.02〜2.46 | 6体中2体が基準割れ |
| 濃紺 `#262A3A` 2px（v240の色） | 1.10〜1.83 | **さらに悪化** |
| **生成り `#FFF3D0` 2px（採用）** | **1.51〜3.09** | ウッドゴーレムのみ割れ |
| 生成り 3px（ウッドゴーレムだけ） | **1.73** | 全6体OK |

輪郭色そのものと背景の比：`#FFF3D0`×W2 = **6.67** ／ `#262A3A`×W2 = 1.91。
参考：`#262A3A`×W4雪山 = 8.69（v240でこれが効いたのは背景が明るかったから）。

**手順**：背景の平均輝度 → 明るいなら濃い輪郭・暗いなら明るい輪郭 → 2pxで測る →
届かない個体だけ3pxに上げる（全体を太くすると絵が潰れる）。

### v245で判明：危険予想は当たらないことがある。必ず測る

MONSTERS.md はW3洞窟を「🔴 最悪（灰色の岩が暗い背景に沈む）」と予想していたが、
**実測したら7体中0体が基準割れ**で、輪郭なしでも 2.24〜4.01 あった。

理由：洞窟の背景は RGB(52,47,66)・輝度 **0.032** と非常に暗く、
灰色の岩は相対的にかなり明るいので、むしろよく見える。
「灰色×岩っぽい背景＝同化」という**言葉のイメージで危険度を決めていた**のが誤り。

| W | 背景の輝度 | 輪郭なしの最低比 | 予想 | 実測 |
|---|---|---|---|---|
| 4 雪山 | 0.591（明るい） | 1.02 | — | 🔴 7/10体が基準割れ |
| 2 夕暮れの森 | 0.092（暗い） | 1.02 | 🟡 | 🟡 2/6体が基準割れ |
| 3 洞窟 | 0.032（最も暗い） | 2.24 | 🔴 | ✅ 0/7体 |

**背景が暗いほど、たいていのまものは見える。危ないのは「背景が明るいワールド」。**

### v246 実測：トゲロンは輪郭なしで全ワールド合格

`spiky` の共通スプライトに使うトゲロン（図鑑07）を、実測した8ワールドの背景色すべてに対して測った。

| W3 洞窟 0.032 | 2.02 | 1.72 | 3.15 |

| W5 火山 0.010 | 2.77 | 2.36 | 4.32 |
| W6 夜の城 0.017 | 2.48 | 2.11 | 3.87 |

| W9 魔界 0.033 | 2.00 | 1.71 | 3.12 |
