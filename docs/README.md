# My HERO ドキュメント

このフォルダは、My HERO の開発を続けるための記録置き場です。
「前に何をどう決めたか」を思い出せるようにしておく場所で、ゲーム本体の動作には一切影響しません。

## Vision

> 子供のころ誰もがぼんやり思った、「こんなゲームがあったらいいな」を形にする

プログラミング初心者が AI を使ってゲームを作り、いずれ息子に
「ゲームは遊ぶだけではなく、自分でも作れるもの」と伝えるためのプロジェクトです。

## 大切にしていること

- 主人公への愛着
- 育成
- ショップ
- 装備
- コレクション
- 成長実感
- 短時間でも夢中になれる体験

最初の目的は収益化ではなく、ゲームとして楽しんでもらうことです。

## 各ドキュメントの案内

| ファイル | 何が書いてあるか | こんなときに読む |
|---------|----------------|----------------|
| [SPEC.md](SPEC.md) | 今のゲームの中身（画面・データ・装備など） | 「これどうなってたっけ？」と思ったとき |
| [CHANGELOG.md](CHANGELOG.md) | いつ何を変えたかの履歴 | 「いつからおかしくなった？」を調べたいとき |
| [TODO.md](TODO.md) | やりたいこと・アイデア・気になっている点 | 思いついたことをメモしたいとき |
| [DEPLOY.md](DEPLOY.md) | 公開のしくみと手順 | 変更を公開ページに反映したいとき |
| [RULES.md](RULES.md) | 開発ルール12項目 | AI に作業を頼むとき |

## リポジトリの構成

```
myhero/
├── index.html                       ← ゲーム本体（これが公開される）
├── my_hero_confirm_modal_fixed.html ← 過去の作業版（履歴保全のため保管）
├── README.md
└── docs/                            ← このフォルダ
```

ゲームは `index.html` 1ファイルで完結しています（画像や JS の外部ファイルはありません）。
