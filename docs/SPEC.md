## 1. 技術構成

| 項目 | 内容 |
|------|------|
| 形式 | 単一 HTML ファイルで完結 |
| 外部依存 | なし（CSS・JavaScript・画像すべて HTML 内に内蔵） |
| 描画方式 | HTML5 Canvas（`<canvas id="cv">`） |
| セーブ先 | ブラウザの localStorage |
| 対応方針 | スマホ縦持ち・タッチ操作前提 |

外部ファイルを読み込まないため、`index.html` を置くだけで動きます。
これが GitHub Pages との相性が良い理由です。

### スマホ対応（実装済み）

- `viewport-fit=cover` + `env(safe-area-inset-*)` で iPhone のノッチ・下部バーを回避
- `user-scalable=no` でピンチズーム無効
- `apple-mobile-web-app-capable` でホーム画面追加時のフルスクリーン対応
- `touch-action:none` / `overscroll-behavior:none` で誤スクロール防止

## 2. 画面レイアウト

固定幅 **390px**（iPhone 標準幅）の縦並び構成です。

```
┌─────────────────┐
│ #hud   HP・コイン等の表示   │  ステータス表示
├─────────────────┤
│ #cv    390 × 390px         │  ゲーム画面（Canvas）
├─────────────────┤
│ #pad   390 × 210px         │  操作エリア
│   #dpad 十字キー / ボタン   │
└─────────────────┘
```

十字キーは CSS の `clip-path` で作られた立体クロス型です。

## 5. ステージ構成

| 項目 | 値 | 出典 |
|------|-----|------|
| ワールド数 | 10 | `NUM_WORLDS=10` |
| 1ワールドあたりのステージ数 | 1 | `STAGES_PER_WORLD=1` |

コメントに「1ワールド=1ステージ（10ステージ化）」とあり、実質10ステージ構成です。

ステージクリア時は**星評価**が付きます（敵撃破率・コイン取得率などから算出）。

## 6. キャラクター

全9種類が定義されています（`CHARS`）。

| 分類 | ID | 特性 |
|------|-----|------|
| 男性 | `men_0` | タフネス（最大HP +25） |
| 男性 | `men_1` | 剣豪（攻撃が速い＆威力+1） |
| 男性 | `men_2` | 未確認 |
| 男性 | `men_3` | 未確認 |
| 女性 | `women_0`〜`women_3` | 未確認 |
| マイヒーロー | `custom` | **特性・スキルなし**（装備で育てるコンセプト） |

### マイヒーロー（自作キャラ）

- 写真をアップロードして丸くクロップし、自分だけの主人公を作れる
- **最大5体**まで保存可能（`CUSTOM_MAX`）
- 名前を付けられる（最大10文字）／後から変更も可能
- あえて特性・スキルを持たせず、「装備で育てる」設計
- 削除時は独自デザインの確認モーダルが出る（誤削除防止）

## 9. セーブデータ（localStorage）

保存キーは全18種類です。すべて `yk_` で始まります。

| キー | 内容 |
|------|------|
| `yk_gold` | 所持コイン |
| `yk_best` | ベストスコア |
| `yk_stars` | ステージごとの星 |
| `yk_unlocked` | 解放済みステージ |
| `yk_char` | 選択中キャラ |
| `yk_owned` | 購入済みアイテム |
| `yk_sword` | 装備中の剣 |
| `yk_shield` | 装備中の盾 |
| `yk_outfit` | 装備中の服 |
| `yk_bg` | 選択中の背景 |
| `yk_ach` | 解除済み実績 |
| `yk_stats` | 各種統計 |
| `yk_ranks` | ランキング記録 |
| `yk_played` | プレイ済みキャラ |
| `yk_custom_list` | マイヒーロー一覧（最大5体） |
| `yk_custom_face` | アクティブなマイヒーローの顔画像 |
| `yk_seen_story` | ストーリー既読フラグ |
| `yk_seen_tut` | チュートリアル既読フラグ |

> ⚠️ **重要**: セーブデータはブラウザごとに保存されます。
> ブラウザの履歴・サイトデータを消すとゲームのデータも消えます。
> 別の端末や別のブラウザにはデータは引き継がれません。
