## のこりの4枚の頼み方（2026-11-18・7人とも同じ注文文。2026-11-19 に 1枚ごとの注文文に）
- 1枚目：ルーベルトの元の絵（`../ta3d_rubert/` の `back_src.png`＝①走る・ジャンプ／`slide_src.png`＝②スライディング／`dirs_src.png`＝③向き8つ／`faces_src.png`＝④ワイプの顔）
- 2枚目：キャラの見本（左＝顔 `heads_v316/<id>.png`・右＝そのキャラの back2_src の直立）。`python3 make_cards.py 出力フォルダ` で作る（文字は入れない）。
  見本に服の色が出ているので、注文文にキャラの名前や服の色を書かなくてよい
- 順番のおすすめ：7人の① → ② → ③ → ④（① がそろえば 500m走で キャラを えらべるようにできる）
- ⚠ **1回の注文で 絵は1枚。添付は2枚だけ（ルーベルトの絵1枚＋キャラの見本1枚）。毎回 新しいチャットで。**
  2026-11-19 の失敗：ルーベルトの4枚＋見本を まとめて添付したら、ChatGPT は1枚しか描けず 4枚の中身が まざった（エルザ：うしろ・横・うしろ・前が1枚に）。
  観客の絵を作った同じチャットでは、前の絵（応援ポーズの7人）を まねして 観客の絵になった（クララ）。
  そこで 2026-11-19 から 1枚ごとの注文文にして、「【描くもの】体の数・ならび」と「前に作った絵は まねしない」を書きこんだ

```
【描くもの】横に4体。4体とも うしろ姿。左から「走る」「走る（足が反対）」「ジャンプ（ひざを曲げて うかぶ）」「右うでを 横へ大きく ふる（足を広げて ふんばる）」
そのまま：1枚目の 体の数・ならび・ポーズ・向き・大きさ・すき間・カメラの角度・質感・背景の緑（#00FF00）
変える：髪型・髪の色・顔・服の色を2枚目と同じに。メガネ・角・かざりなど、2枚目にあるものは全部つける。服の形は1枚目のまま

```
