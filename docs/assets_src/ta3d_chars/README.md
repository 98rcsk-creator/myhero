## ゲームに入れる（2026-11-21〜・試作25）
- `python3 prep_char.py <ID> ...` → `test/ta3d_chars/<ID>.js`（500m走が えらばれたときだけ 読みこむ）。`--check <フォルダ>` で ルーベルトと ならべた 一覧の画像を作る
- 切り分け：all4 は 白い線で 4つに分けて、枠の中を 体ごとに 切る（くっついた 顔は いちばん うすい所で 切る）。はなれた 小さな かけら（髪の毛先）は 消す
- 切り抜き：ふちから つながった 緑だけ 背景にする（体の中の 明るい緑＝ジルヴェスターの トサカ・服は のこす）。ほかのキャラは かこまれた 緑（髪の すき間）も 背景。ふちの 緑の まざりは 色を もどす
- 大きさ：ポーズの まとまり（直立・パンチ・よーい／走る・ジャンプ／スライディング／向き8つ）ごとに、ルーベルトの 同じポーズの 体の高さに そろえる。顔は ルーベルトの 顔のマスと 同じ位置。7つ目（ふつうの顔）は heads_v316
- 2026-11-21 の 診断（6人）：ならび・向き・数は 6人とも 正しい。直したのは 切り抜きだけ（ジルヴェスターの トサカの穴・メルティの 髪の毛先の 緑・クララの 顔どうしが くっついて 分かれない）
  - のこっている 絵の ちがい：メルティの「パンチ」は ポニーテール（back2 の絵の まま）。ジルヴェスターの 直立・パンチ・よーい の トサカは 走る絵より 明るい緑
- 2026-11-21 エルザ：ならび・向き・数 正しい。金髪・白い服の ふちに 黄緑の線が のこったので、緑のキャラ いがいは いちばん外の 2px を けずるようにした（7人とも 作りなおし・ファイルも 少し小さくなった）
