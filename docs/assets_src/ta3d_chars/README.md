## のこりの4枚の頼み方（2026-11-18・7人とも同じ注文文）
- 1枚目：ルーベルトの元の絵（`../ta3d_rubert/` の `back_src.png`＝①走る・ジャンプ／`slide_src.png`＝②スライディング／`dirs_src.png`＝③向き8つ／`faces_src.png`＝④ワイプの顔）
- 2枚目：キャラの見本（左＝顔 `heads_v316/<id>.png`・右＝そのキャラの back2_src の直立）。`python3 make_cards.py 出力フォルダ` で作る（文字は入れない）。
  見本に服の色が出ているので、注文文にキャラの名前や服の色を書かなくてよい
- 順番のおすすめ：7人の① → ② → ③ → ④（① がそろえば 500m走で キャラを えらべるようにできる）

```

そのまま：ポーズ・体の形・大きさ・ならび・すき間・カメラの角度・質感・背景の緑（#00FF00）

顔が見える絵は、顔のつくり（目・まゆ・髪）は2枚目、表情（おこる・いたい・こわい・わらう など）は1枚目と同じにする
剣・盾・影・地面・文字・エフェクトは描かない。サイズは1枚目と同じ以上。
```
