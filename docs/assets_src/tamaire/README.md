# 大運動会「玉入れ」の元の絵

ルーベルトの玉入れのポーズ（6つ）を ユーザーが ChatGPT で作る。届いたら このフォルダに `throw_src.png` で置く（加工前のまま・§1-17）。

- 1枚目：`../ta3d_rubert/back_src.png`（ルーベルトのうしろ姿）
- 2枚目：ポーズの見本（棒人間）。`python3 make_pose_guide.py 出力.png` で作る。絵として使うものではない
- ほかの7人は、ルーベルトの絵ができてから `../ta3d_chars/README.md` の共通の注文文で入れかえる

```
1枚目の男の子（うしろ姿）と同じキャラ・同じ質感・同じ大きさ・同じカメラ（うしろの少し上から）で、運動会の「玉入れ」のポーズを6つ描いてください。
2枚目は ポーズの見本の棒人間です。ポーズだけまねして、絵がら・灰色・矢印・線はまねしないでください。
横3列×たて2段。6体とも同じ大きさで、足元まで全部入れる。1体ずつ十分にすき間をあける。
キャラは、画面の奥にある高いかごへ、赤い玉を投げ入れようとしている。

【上の段（左から）】
1. かまえる：足を少し開いて立つ。右手で赤い玉を持ち、右の腰の横にさげる。顔は奥の高いところを見上げる
2. ためる：ひざを曲げてしずむ。右手（玉）を右うしろへ大きく引く。玉が体の右うしろに見える
3. 投げる：つま先立ちで体をのばし、右手を頭より高く、奥へふり上げた瞬間。手は開いていて、玉はもう持っていない

【下の段（左から）】
4. ひろう：かがんで、右手で足元の赤い玉をつかむ
5. かった：両手を高く上げてジャンプ（バンザイ）
6. まけた：肩を落としてうつむく。両手はだらんと下

赤い玉は、にぎりこぶしくらいの大きさで、赤一色の布のお手玉。1・2・4だけに描く。
服・髪・塗りは1枚目とまったく同じ。
かご・地面・影・ほかの玉・線・背景・文字・エフェクトは描かない。背景は明るい緑一色（#00FF00）。サイズは 2048×1536 以上。
```
- 玉は 赤組（プレイヤー）なので赤で描いてもらう。投げた瞬間（3）は 玉を持っていない絵にして、飛ぶ玉はゲームが描く
